# **App Name**: SafoRoom

## Core Features:

- Login/Authentication: User authentication with role-based access (student vs. admin).
- Student Dashboard: Student dashboard displaying room status, deadlines, and quick actions.
- Room Application Form: Room application form for students to submit their preferences.
- Admin Dashboard: Admin dashboard with system statistics and quick actions.
- Room Management: Room management interface for CRUD operations on rooms.
- Allocation Configuration: Ability to configure priority rules for the allocation algorithm.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and security, suitable for an administrative tool.
- Background color: Light blue (#E8EAF6), a desaturated shade of the primary to create a calm, professional backdrop.
- Accent color: Purple (#7E57C2), an analogous color, for highlighting interactive elements.
- Body and headline font: 'Inter', a sans-serif font for clear and modern readability across all devices.
- Use minimalist, consistent icons to represent various functions and room types, enhancing user experience.
- Responsive, grid-based layout for scalability.
- Subtle transitions and feedback animations on button presses
